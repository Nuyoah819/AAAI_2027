## 2.5.2 基于异配关联检测与解耦对比学习的跨模态去噪方法

本项目将跨模态噪声问题转化为异质图上的异配关联检测问题，采用一种频率解耦与对比学习的结构增强方案，如图6所示。其核心是将拓扑结构分离为同配子图和异配子图，进 $\bar { \mathsf { m } }$ 从结构层面提升表征的纯净度与判别性。拟采用的关键技术如下。

## （1）关联异配性量化方法

在非监督的多源遥感异质图中，由于缺乏地物标签指引，异配边可以通过度量属性语义与拓扑结构之间的吻合程度来辨识。本项目拟采用一种双路联合度量方式，通过属性视角与结构视角的互相关效应，自适应辨识非理想观测下的拓扑偏差。针对边 $e _ { i j }$ 上的节点 和节点 ，利用属性编码器 $f _ { \theta }$ 提取节点的属性语义以计算特征相似度 ${ \pmb s } _ { X }$ ，同时利用结构编码器 $g _ { \theta }$ 提取节点在图中的角色嵌入以计算结构相似度 ${ \pmb S } _ { A }$ ，计算过程如下：

$$
\left\{ \begin{array} { l l } { \pmb { \mathscr { s } } _ { X } = \sin \left( f _ { \theta } \left( \mathbf { x } _ { i } \right) , f _ { \theta } \left( \mathbf { x } _ { j } \right) \right) } \\ { \pmb { \mathscr { s } } _ { A } = \sin \left( g _ { \theta } \left( \mathbf { p } _ { i } \right) , g _ { \theta } \left( \mathbf { p } _ { j } \right) \right) } \end{array} \right.\tag{4}
$$

其中，节点 的结构特征 $\mathbf { p } _ { i }$ 由 步随机游走到达自身的概率向量组成，即$\mathbf { p } _ { i } = [ R W _ { i i } , R W _ { i i } ^ { 2 } , \cdots , R W _ { i i } ^ { d } ] \in R ^ { d }$ 。然后，将上述双路相似度编码向量输入到下列的异配边判别器，计算边 $e _ { i j }$ 的置信度得分 $s _ { i j }$ ：

$$
s _ { i j } = \mathrm { S i g m o i d } \left( \mathrm { M L P } \left( \left[ \pmb { \mathscr { s } } _ { X } \| \pmb { \mathscr { s } } _ { A } \right] \right) \right)\tag{5}
$$

在该机制下，若属性相似且结构紧密，则判定为高置信度同配关联（如连续水体

内部）；若属性相近但结构逻辑疏离（如时空偏差导致的跨类连接），该机制会减小属性相似度将其识别为低分异配边。判别依据由自适应阈值决定。

## （2）自适应异配关联阈值演化策略

确定异配边解耦的阈值是一个难点，本项目拟采用一种自适应阈值演化的方案来解决。其核心在于通过动态调整判别边界，实现从模糊拓扑向确定性结构的自进化。基于前述小节计算得到的关联置信度得分 $s _ { i j }$ ，设定初始的高位阈值 与低位阈值 （满足 $H \gg L )$ ），建立三段式动态解耦空间：

$$
\left\{ \begin{array} { l l } { G _ { h o m o } , } & { s _ { i j } \geqslant H } \\ { G _ { h e t e } , } & { s _ { i j } \leqslant L } \\ { G _ { h a r d } , } & { L < s _ { i j } < H } \end{array} \right.\tag{6}
$$

其中， $G _ { h o m o }$ 是同配区的低频子图，被判定为高可靠的同类连接； $G _ { h e t e }$ 是异配区的高频子图，被识别为跨类边或噪声关联； $G _ { h a r d }$ 是困难区的语义模糊待定边，其归属随模型的迭代动态演化。

本项目采用课程学习的交替优化策略，通过最小化损失函数来驱动阈值演化。在每一次迭代中，阈值根据当前预测得分的梯度方向进行自适应更新：

$$
H \colon = H - \eta \cdot { \varDelta _ { H } } \ , \quad L \colon = L - \eta \cdot { \varDelta _ { L } }\tag{7}
$$

其中，步长 $\Delta _ { H }$ 和 $\Delta _ { L }$ 由当前得分分布的统计特性与聚类一致性梯度共同决定，促使 与 相互靠近并最终达到收敛状态。这种自适应压力机制确保了原本处于中间地带的困难关系被逐步挤压，并精准分流至正确的子图中，不仅规避了人工调参的盲目性，更从底层解决了多源遥感数据中异构关联的虚假性问题，为接下来执行的频率解耦滤波与聚类优化提供了稳健的结构保障。

## （3）基于频率解耦的图对比学习

在解耦后的子图上，本项目采用谱域解耦滤波与图对比学习的特征增强框架，从多源遥感噪声背景中提取纯净的地物表征。首先，利用解耦后的同配子图与异配子图实施针对性滤波，通过低通平滑增强语义一致性，同时通过高通差分抑制异配干扰。拟采用的频率解耦滤波定义如下：

$$
\begin{array} { r } { \mathbf { Z } _ { l o w } = \sigma \bigg ( \tilde { \mathbf { D } } _ { h o m o } ^ { - \frac { 1 } { 2 } } \tilde { \mathbf { A } } _ { h o m o } \tilde { \mathbf { D } } _ { h o m o } ^ { - \frac { 1 } { 2 } } \mathbf { X } \cdot \boldsymbol { \theta } _ { l o w } \bigg ) } \\ { \mathbf { Z } _ { h i g h } = \sigma \bigg ( \bigg ( \mathbf { I } - \tilde { \mathbf { D } } _ { h e t e } ^ { - \frac { 1 } { 2 } } \tilde { \mathbf { A } } _ { h e t e } \tilde { \mathbf { D } } _ { h e t e } ^ { - \frac { 1 } { 2 } } \bigg ) \mathbf { X } \cdot \boldsymbol { \theta } _ { h i g h } \bigg ) } \end{array}\tag{8}
$$

其中 表示网络参数， 和 为邻接矩阵和度矩阵。随后，在双路滤波输出视角间引入对比损失，通过最大化节点在低通视角与高通视角下的互信息，强制模型在训练过程中滤除与地物本质无关的冗余观测噪声。该机制利用对比损失函数拉近同配节点间的距离，并推开异配节点的距离，从而提取出跨频率稳定的核心特征。本方案能够有效剥离不具备语义关联的随机信号，仅保留在谱域两端均有稳定贡献的特征分量，为接下来的鲁棒聚类提供高判别性的特征表示。
