# Documentation Index

This project keeps code entry points at the repository root and groups most
documents under `docs/`.

## Sections

- `docs/governance/`: workspace rules and non-negotiable constraints
- `docs/background/`: problem statement and early reference notes
- `docs/evolution/`: algorithm evolution history
- `docs/planning/`: route selection and planning material
- `docs/reports/iterations/`: per-version experiment, review, and verdict files
- `docs/writing/`: manuscript, references, and presentation artifacts
