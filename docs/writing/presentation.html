Problem definition

核心问题：由属性-结构不匹配引发的异配噪声关联

在无监督 attributed graph clustering 中，输入图的边并不等同于语义同类关系。若属性空间显示两个节点接近， 但结构角色或局部拓扑显示二者属于不同语义区域，原始边就会成为异配噪声关联；反过来，结构上紧邻但属性冲突的边也会污染低通聚合。

形式化视角

给定图 G = (V, E, X)，每条候选边 eij 同时携带属性相似性、 结构接近性和局部频率响应。项目关注的不是单纯的 heterophily，而是 属性证据与结构证据发生冲突时产生的伪关联。

s_X(i,j) = sim(f_theta(x_i), f_theta(x_j)) s_A(i,j) = sim(g_theta(p_i), g_theta(p_j)) gap(i,j) = |s_X(i,j) - s_A(i,j)| edge concordance c_ij = E_phi(s_X, s_A, gap, local spectrum)
为什么困难

异配边不全是噪声，噪声边也不总是低相似

真实异配边可能提供类别边界信息；噪声边也可能在属性上高度相似。若只做硬删除，容易丢掉有用边界； 若直接在原图上低通平滑，又会把跨类噪声传播到簇内部。

因此，本项目把问题转化为边级可靠性估计：一条边应被收缩、抑制、还是暂时保留为困难证据。

Model overview

最终模型总览：从边级一致性到可靠聚类后验

CSTC 的整体设计逻辑是：先判断边是否与当前学习到的聚类几何一致，再决定它进入低频收缩通道、 高频纠偏通道或困难区，最后用可靠性校准的 transport/posterior 读出聚类标签。

1. 边置信建模

用属性相似、结构角色和局部差异估计边的一致性，而不是默认信任原始邻接。

2. 软拓扑划分

用可学习阈值把边连续分配到同配、异配和困难区，避免不可导硬剪枝。

3. 频谱解耦传播

同配通道低通收缩，异配通道高通纠偏，把噪声边从平滑主干中剥离。

4. 可靠读出

通过统一的聚类读出与安全后处理得到标签，不使用真实标签或测试指标进行选择。

Core mechanism

可微拓扑收缩如何处理属性-结构不匹配

可微拓扑收缩的关键不是“删边”，而是把每条边的语义角色变成一个连续变量。 高一致性的边被收缩为低频同配支撑；低一致性或冲突边被送入高频纠偏支路； 中间区保留为困难证据，随训练逐步被分流。

这样处理后，属性-结构不匹配不会直接污染主消息传递路径，而是先经过边置信校准，再决定它对表示学习的贡献方向。

m_homo(i,j) = sigma((c_ij - H) / tau) m_hetero(i,j)= sigma((L - c_ij) / tau) m_hard(i,j) = sigma((c_ij - L) / tau) * sigma((H - c_ij) / tau) Z_low = LPF(A_homo, X) Z_high = X - HPF(A_hetero, X) Z = fuse(Z_attr, Z_low, Z_high)
机制解释

从“拓扑是否可信”到“拓扑怎样使用”

对于属性相似且结构一致的边，模型增强其低频平滑权重；对于属性相似但结构矛盾的边， 模型降低其收缩权重，并把它作为高频冲突信号参与纠偏。

这种设计保留了异配边可能有用的边界信息，同时避免把异配噪声当作同类邻居扩散。

Mechanism details

面对 Edge Heterophily Challenge 的去噪策略

频谱过滤

同配低通只在可靠拓扑上发生

低通聚合不再盲目使用全图邻接，而是由同配 mask 加权。这样可以减少跨类边在平滑过程中的语义泄漏。

拓扑修正

异配边被降权而非简单删除

异配 mask 对应高频冲突支路，保留边界信息的同时削弱其作为同类传播边的作用。

边置信建模

困难边进入可学习缓冲区

中间置信度边不被立即判死，而是随着训练中的表示、局部频率和后验一致性继续演化。

结构重构

从原始图转向校准后的传播图

模型最终使用的是由边置信和频谱通道共同决定的有效传播结构，而不是原始邻接的直接复制。

可靠读出

避免用后处理替代核心机制

最终读出统一使用无标签证据。PubMed 的尺寸压力修正只看簇规模和嵌入边界，不使用真实标签或数据集名。

失败边界

仍未完全解决强异配图

Wiki、Squirrel、Chameleon 仍低于目标，说明当前机制在极端异配/高噪声拓扑上的频谱纠偏还不充分。

Expected contribution

预期贡献与表述边界

论文写作应强调一个清晰科学问题和一条统一机制主线，避免把实验迭代史包装成模块堆叠。 当前最稳妥的贡献表述如下。

问题贡献

将无监督图聚类中的性能退化归因到属性-结构不匹配引发的异配噪声关联，并用边级一致性进行建模。

方法贡献

提出可微拓扑收缩层，把候选边连续映射到同配、异配和困难区，避免硬剪枝和数据集专用拓扑选择。

频谱贡献

将低通平滑限制在可靠收缩拓扑上，并把异配冲突作为高频纠偏信号，从传播路径上降低频率混叠。

实验贡献

在统一无标签选择协议下，当前版本在 9 个数据集中 6 个达到 ACC SOTA，同时保留对未解决数据集的误差分析。
